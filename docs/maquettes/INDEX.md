# Index des maquettes

137 planches, 12 pages. Source : canevas Claude Design https://claude.ai/artifact/86d32GRYa7h2pXc9FvNmW8 (version 1792885641-d982, validée le 25 octobre 2026).

- `png/` : capture de chaque planche (polices de repli : Cinzel et Roboto Flex n'étaient pas chargées au rendu, la typo réelle est dans `docs/design/design_tokens.json`).
- `texte/` : texte visible de chaque planche (pour chercher un libellé avec grep).
- `html/` : source HTML de chaque planche ; les styles en ligne donnent les valeurs exactes (couleurs, espacements, tailles). Le runtime d'affichage n'est pas fourni : ces fichiers se lisent, ils ne s'ouvrent pas tels quels dans un navigateur.

Les identifiants entre crochets (ex. [C3], [D1]) sont ceux utilisés dans `COMPOSANTS.md`, `CONFORMITE.md` et le cahier.

**[D1] (`D01-Jeu-De-Donnees`) est la planche de référence des fixtures de test** : personnages, rencontres et séances identiques dans les maquettes et dans les tests du moteur.
