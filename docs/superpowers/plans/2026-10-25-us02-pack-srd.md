# US-02 · Pack SRD 5.2.1 français (schémas et échantillon vertical) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produire `srd-5.2.1-fr.dndpack` à partir de sources JSON validées, avec un échantillon vertical (Guerrier et Champion, 4 Historiques, Humain, dons, armes, armures, états) qui contient tout ce que référence la fixture d'Aldric niveau 1.

**Architecture:** `dnd_content` porte le format : identifiants, DSL v1 validé par une table de schémas, modèles freezed des entités (champs inconnus refusés), manifeste, archive `.dndpack`, contrôles d'intégrité et de références. `tools/srd_builder` lit un fichier JSON par entité, appelle ces validateurs et écrit l'archive, ou échoue en listant tous les problèmes.

**Tech Stack:** Dart 3.13 (Flutter 3.47.7 via fvm), freezed 4 + json_serializable 6 (`checked: true`, `disallowUnrecognizedKeys: true`), `archive` (zip), `crypto` (sha256), `args`, `test`.

**Spec:** cahier §1.3 (attribution), §7, §10.3, §11.1, §11.3, ENF-09 ; `docs/dsl/DSL_V1.md` (validé le 25 oct. 2026) ; format de pack validé le 25 oct. 2026, consigné par la tâche 1 dans `docs/packs/FORMAT_DNDPACK.md` ; carte Trello US-02.

## Global Constraints

- Identifiant de contenu : `{namespace}:{type}:{slug}`, regex `^[a-z0-9]+(?:-[a-z0-9]+)*:[a-z]+(?:-[a-z]+)*:[a-z0-9]+(?:-[a-z0-9]+)*$`, slugs anglais stables.
- Le type `resource` est réservé aux clés de ressources (`srd:resource:second-wind`) : jamais une entité, jamais vérifié comme référence.
- Distances en pieds, masses en kg, prix en pièces de cuivre (`cost_cp`).
- Texte de règles : **copié du PDF français officiel**, jamais traduit ni reformulé ; vocabulaire SRD (« état », « Bottes d'armes »…).
- Attribution (manifeste), mot pour mot : « Cette œuvre inclut du matériel issu du System Reference Document 5.2.1 (« SRD 5.2.1 ») de Wizards of the Coast LLC, disponible à l'adresse https://www.dndbeyond.com/srd. Le SRD 5.2.1 est régi par la Licence Creative Commons Attribution 4.0 International, disponible à l'adresse https://creativecommons.org/licenses/by/4.0/legalcode. »
- Aucun nom de marque dans le code ou les noms (« compatible 5E » seulement).
- Plafonds à la lecture d'un pack (ENF-09) : 20 Mo, 10 000 entités, profondeur JSON 32.
- Pack SRD : `id` `377190b6-2dfa-4b38-83be-1c4c6d0cf55d`, `namespace` `srd`, `origin` `srd`, `licence` `CC-BY-4.0`, `locale` `fr`, `dsl_version` 1, `version` `1.0.0`.
- Couverture `dnd_content` ≥ 90 % (cahier §12.1).

## Review Focus

1. **Archive reconstruite deux fois** : deux builds des mêmes sources doivent donner des octets identiques (zip déterministe, entités triées par id) → test dans la tâche 4.
2. **Pack corrompu ou hostile à la lecture** (somme de contrôle fausse, JSON trop profond, trop d'entités, fichier manquant dans le zip) → erreur nommée, jamais d'exception brute → tests dans la tâche 4.
3. **Doublon d'identifiant** entre deux fichiers sources → le build échoue en nommant les deux fichiers → test dans la tâche 5.
4. **Nom de fichier incohérent avec l'id** (`sources/weapon/longsword.json` qui déclare `srd:weapon:long-sword`) → erreur, pour garder une source par entité retrouvable → test dans la tâche 5.
5. **Effet valide mais référence vers un type inattendu** (`grant_proficiency kind: skill` vers `srd:weapon:longsword`) → erreur de type de référence → test dans la tâche 4.
